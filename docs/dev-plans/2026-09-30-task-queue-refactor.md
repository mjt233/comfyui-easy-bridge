# 任务队列功能重构

【任务日志】界面中，调整为【待调度】和【已提交】两个页签。

## 概念定义

### 待调度

系统收到工作流提交请求时，首先会将任务推送到【待调度】队列。

1. 当工作流的执行提供商为“分组”，且选定的“分组”下没有空闲可用的实例时，该任务会一直处于【待调度】队列中排队等待
2. 当工作流的执行提供商为非“分组”，且执行提供商未处于空闲状态时，该任务会一直处于【待调度】队列中排队等待

一旦【待调度】的任务中匹配的执行提供商可用了，则顺序将任务提交执行


### 已提交

工作流已真实提交到具体的执行提供商（如RunningHub、ComfyUI）时，任务进入该列表。
